# GameMale 青龙配置助手 · 数据说明

扩展在用户点击按钮后读取 GameMale Cookie（包含 HttpOnly 登录凭据），在当前页面内存中构建配置，按用户选择复制到本地剪贴板。用户可填写论坛用户名、密码、安全问题及答案，以及青龙面板地址、Client ID 和 Client Secret。

点击「连接并读取现有配置」时，扩展把 Client ID / Client Secret 直接发送到用户填写的青龙面板，获取令牌并读取配置。点击「将预览写入青龙」时，扩展把用户预览的完整配置直接发送到同一面板，配置可能包含 Cookie、论坛用户名、密码、安全问题答案、Cloudflare 密钥和其他账户信息。论坛 Cookie 不发送到第三方中间服务。

扩展开发者不接收或保存这些数据，扩展不含分析、遥测或广告服务，不使用浏览器 storage。扩展仅在当前页面内存中持有凭据；刷新、关闭或点击清空按钮后释放。剪贴板及已经保存到用户面板的数据不会随页面清空，请由用户自行管理。浏览器会记住已授予的站点访问权限。

Firefox 包声明 `authenticationInfo` 和 `websiteContent` 数据权限，用于上述向用户指定面板传输认证信息、Cookie 和配置内容的功能；这不表示数据会传给开发者。使用 HTTP 面板时传输不加密，建议使用 HTTPS。
